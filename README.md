Project overview
A retail financial analytics project built from Excel source data. It combines spreadsheet-based analysis, CSV datasets, an interactive HTML/CSS/JavaScript dashboard, and MySQL analysis to review sales, product profitability, expenses, inventory and procurement.

The dashboard fetches the CSV files using these exact filenames. The SQL links in the dashboard also expect the eight SQL scripts and `README_SQL.md` in the repository root.
